# No secrets under Chromium's shared Linux key (#717)

On Linux without a working keyring, Electron names the keyring as its
backend but seals with the key built into every Chromium, tagged `v10`.
YapYap now looks at the sealed data rather than the backend's name: it keeps
no secret so sealed, so Settings says it cannot keep one, and forgets any
secret already kept that way, so it is asked for again.
