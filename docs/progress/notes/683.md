# File → New Chat with Number… is gone (#683)

WhatsApp Web's own **New chat** now opens a chat with a number that is not
in your contacts, so YapYap's copy of it (#215) is removed: the menu item,
its window and page, the `chat:open-number` operation and the preload's
`chat` API, its text, tests and the guide's section. The File menu now
starts with Settings on Windows and Linux, and holds only Close on macOS.

Chat links (`wa.me`, `api.whatsapp.com/send`, `whatsapp://send`) still open
their chat, and AI agents still open chats by number through WhatsApp's
`/send?phone=` link.
