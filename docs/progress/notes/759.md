# OpenSSF Scorecard pinned back to v2.5.0 (#759)

`ghcr.io/ossf/scorecard-action:v2.6.0` stopped pulling on 2026-11-24: its
image index names an amd64 manifest that ghcr.io answers with 404
(ossf/scorecard-action#1752). The Scorecard workflow uses v2.5.0 again,
whose image pulls, and Renovate skips v2.6.0 exactly, so a fixed release
can still come in.
