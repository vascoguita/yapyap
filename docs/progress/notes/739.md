# Suggestions follow an edit of the chat's last message (#739)

An edit keeps a message's ID, and the assistant told messages apart only
by their IDs, so after the contact edited the chat's last message it kept
the suggestions written for the old text. The page probe now also hashes
what the last message says, its text and emoji without the message it
quotes, and hands over only that hash. The assistant names the last item
by it too, so an edit counts as a new last item and suggestions are made
for it again, once. An edit of an older message asks nothing, to avoid
extra requests, and editing the user's own last message is no send.

The fake WhatsApp page gets edits through the E2E helper `messageEdited`,
which changes the row's text in place and adds "Edited" beside it, and an
E2E test checks that new suggestions come for the edited text.
