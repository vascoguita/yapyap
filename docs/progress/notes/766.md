# Adjustable summary threshold and messages read, in one group (#766)

Settings › AI Assistant keeps everything the assistant does in chats in
one **In chats** group: the main switch, **Suggest replies**,
**Summarize unread messages** and **Messages it reads**. How many unread
messages start a summary is now a setting (`assistant.summarizeFrom`, 10
by default), set with a − / + stepper on a line of its own under the
summary switch, faded while summaries are off. **Messages it reads**
takes any ten from 10 to 200 (50 by default) with the same stepper,
instead of 20, 50 or 100, and its description names all three features
that read it. The group of chats the assistant may read is now called
**Chats it may read**, so it is not confused with **In chats**. The
maintainer chose design A (steppers) from a canvas of three.
