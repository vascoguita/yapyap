# The last of the UI review (#677)

- The in-chat assistant takes its type, corners and spacing from the windows'
  tokens, in pixels inside WhatsApp's page. Its hints grow from 12.5 to 13 px
  and its menu items' corners match the windows' controls.
- Chrome windows come in three sizes, `WINDOW_SIZES`: a 440 px dialog, a
  600 × 640 px medium window and an 820 × 640 px large one. The brand guide
  lists which window is which.
- Proxy sign-in and the recovery page, checked on screen in both themes. The
  proxy window was too short for its buttons; it is 480 px tall now.
