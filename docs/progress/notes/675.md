# UI text follows one set of rules (#675)

A review of every string in `en.json`, with the rules now written down in the
brand guide's new "Words" section:

- The Spelling languages window pointed to Settings → Spelling, which does
  not exist; it now says Settings → General.
- Contractions are gone, Settings places are always written with an arrow,
  and the assistant bar's buttons are in Title Case like every other button.
- Failures that gave no next step now say "Try again", and the settings
  import confirmation's button says **Import Settings**.
- Secrets are kept by the "keychain" everywhere; the AI Assistant page had
  said "keyring".
