# Suggestions stay with their chat (#730)

When the user switched chats, the previous chat's suggestions showed for a
moment in the new one. WhatsApp draws the new chat at once and the bar
comes back into it within a second, while YapYap learns that another chat
opened only at its next look. The bar's state now names the chat its
suggestions and notice were made for, and the page shows them only while
that chat's header is the one open.
