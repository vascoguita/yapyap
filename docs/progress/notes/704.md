# Spelling dictionaries in Settings (#704)

Settings › Spelling now shows how each dictionary in use stands:
"Downloading…" and "Ready" muted, "Could not download" in the danger
color with **Try Again**, from Electron's dictionary events, or ready when
its file is on disk. The page asks again every second while one
downloads. Try Again sets each session's languages anew, which makes
Chromium ask again. A new **Dictionaries** group, between the switch and the
languages, says they stay on this computer and in which folder, with **Show
Folder**. It also says that unticking a language keeps its dictionary,
and offers **Remove Unused** when files no language in use needs are
there. A row with a state stacks the language's two names to make room.
The text and layout went through the design plugin.
