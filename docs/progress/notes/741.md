# One working look, and dictionary downloads that show (#741)

Ticking a spelling language showed no download: Settings asked before
Chromium reported one. Now, while spell checking is on, a language in use
with no dictionary on disk and no event yet counts as downloading, and
the page asks again when spell checking is turned on.

Progress now looks the same everywhere, as designed with the design
plugin from the owner's idea: a thin light that travels around the edge of
the pill that works (`WORKING_EDGE`, src/shared/working-edge.ts), held
still and faded for people who ask for less motion. The AI assistant's
blank suggestions and its rewrite button use it in WhatsApp's page, and
Settings' stylesheet carries the same rule, which a test keeps alike. A
dictionary shows a "Downloading…" pill with it for at least 800 ms, then
a check and "Downloaded" for 4 s, then nothing; one already on disk shows
nothing. While two or more download, the Languages summary says so too.
