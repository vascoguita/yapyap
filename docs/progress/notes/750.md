# Suggestions never show the model's reasoning (#750)

A model could write a line about why it chose its replies before them,
and that line showed as a suggestion to send. The request now asks for
each reply between `<reply>` tags, and only what they hold becomes a
suggestion; anything else the model writes is left out. A model that
fences none still has its lines read, the last three, which come after
any reasoning. Chat text that holds a `<reply>` tag is made harmless, like
the other tags, so a message cannot pass for a reply. The change is in the
task, so the cached instructions and chat stay byte-identical.
