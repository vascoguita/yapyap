# Fewer, clearer ways to fix WhatsApp (#691)

**View → Reload** now always reloads the active account's WhatsApp, and
dismisses the recovery screen if it shows; Electron's own reload role
reloaded whatever had the focus, the account sidebar included. **Force
Reload** and its shortcut are gone: WhatsApp loads through its service
worker, so when Reload does not help, **Clear Cache and Reload** does.
**Reset Session…** is now **Log Out and Delete Data…**, which says what it
does.
