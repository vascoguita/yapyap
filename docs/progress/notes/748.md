# Custom code shows what all accounts run in an account (#748)

Choosing one account under **Applies to** in Settings › Custom code showed
empty boxes, although the code for all accounts runs there first, so what
was written read as lost. While one account is chosen, the page now shows
the code for all accounts read-only above the account's own, says it runs
there first, and the account's empty boxes say their code is that
account's only. Nothing is shown when the code for all accounts is empty.
