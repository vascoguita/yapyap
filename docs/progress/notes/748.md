# Custom code names what it edits, and folds what all accounts run (#748)

Choosing one account under **Applies to** in Settings › Custom code showed
empty boxes, although the code for all accounts runs there first, so what
was written read as lost. A first fix showed that code read only above the
account's boxes, which looked like more boxes to edit. Reviewed with the
design plugin, the page now names the code being edited by its scope ("CSS
for all accounts", "CSS for Work"), keeps the account's own boxes right
under the picker, and folds the code for all accounts under them in one
row, "Runs after the code for all accounts", naming the parts it holds.
Show opens it as plain monospace text on a muted fill, never a field, with
Edit for All Accounts to switch to it.
