# AI suggestions float above WhatsApp's message box (#743)

The suggestions row no longer sits in a flat band on top of WhatsApp's
rounded message box. The notice and the chips float on the chat's
wallpaper, with the shadow WhatsApp gives its own floating box, lined up
with its edges. The control that folds them away is now the first chip in
the row, where the chip they fold into shows too, so it never moves. While
suggestions are written, one chip says "Writing suggestions…" with the
shared working edge, instead of three blank ones. They stay while the user
types, a little fainter, and the others stay after one is picked; picking
one over a draft replaces it, with Undo. Designed and reviewed with the
design plugin on the showcase page, in both themes.

When no suggestions come, the row now says why instead of showing nothing:
"No suggestions this time." with Try Again when the model answered nothing
usable, "The model declined to suggest replies in this chat." when it
declined, or the same problem a rewrite would show, with Try Again or the
way to Settings that mends it.
