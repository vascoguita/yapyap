# Report a Problem copies the report and records traces (#693)

**Copy Diagnostics** and **Record a Performance Trace…** left the Help
menu, which now holds Keyboard Shortcuts and Report a Problem. The Report
a Problem window gained **Copy Report**, which copies the description and
diagnostics without opening GitHub, and an "Is YapYap slow?" section that
records a performance trace. Its failure message points to Copy Report.
The recovery screen keeps its own Copy Diagnostics button.
