Progress notes (#660): each pull request adds its note as
`docs/progress/notes/<issue>.md` instead of appending to one page, so
merging one pull request no longer puts the others in conflict and makes
them rerun CI. `docs/progress/index.md` keeps the current state and
conventions and lists the notes in issue-number order on the site
(Developers › Progress); `check-progress-notes.ts` checks their names
(ADR 0007).
