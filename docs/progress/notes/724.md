# Call permission questions on top of the call (#724)

YapYap's question about the microphone and camera opened as a window of
its own, with no parent, so it could open behind a call's window, which
stayed blank while it waited. The question now belongs to the window
that asked: a call's own window, or, for an account's view, which
Electron gives no window, the window in front. macOS's "does not let
YapYap use" notice goes on top of the same window.
