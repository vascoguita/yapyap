# Suggestions for whatever the chat ends in (#723)

The AI assistant suggested replies only when the open chat's last item was
someone else's text. Now it suggests what to send next whenever a chat
opens or something new appears in it, whoever sent the last item: a
follow-up when it is the user's own. The chat reader names what is not
text, as WhatsApp's markers tell it (mapped on the maintainer's session,
markers only): calls, stickers, animated emoji, voice messages, videos,
photos, media not downloaded yet, and anything else with a bubble but no
words. The model reads them as "[a photo]", "[a call]" and so on, with
any caption, and a call with no sender, as its row does not say who
called. Emoji-only messages, which have no copy mark, are read from their
emoji images instead of being left out. The model is no longer asked to
answer NONE. Settings and the guide say when the chat is read, and agents
reading a chat get each message's `kind` too. Landmarks are at version 11.
