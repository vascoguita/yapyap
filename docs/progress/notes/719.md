# The secret store meets the mutation gate (#719)

`apps/desktop/src/main/secrets/` joins the mutation scope and ADR 0005's
list. New tests cover the `unknown` backend, a file of another version, a
secrets field that is not a map, and backend names outside Linux, and the
backend and file checks became single conditions: `secret-store.ts` scores
98.15%, its two survivors changing nothing a caller can see.
