# Start in the background, only at login (#699)

**Start minimized** hid the window on every launch, so opening YapYap by
hand showed only a tray icon. It is now **Start in the background**, right
under **Start at login** and faded while that is off, and it acts only when
the system starts YapYap at login: every login entry passes
`--started-at-login` (Windows login items, the XDG autostart entry, the
Flatpak's Background portal request), and on macOS YapYap asks Electron
whether it was opened at login. An XDG or Windows entry from before the
flag gains it when YapYap starts. A faded setting now shows its name in
the hint's color instead of a lower opacity, which kept its hint below AA
contrast.
