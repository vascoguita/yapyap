# The rewrite menu shows over the suggestions tray (#770)

Since the suggestions became a tray over WhatsApp's footer (#765), the
rewrite button's menu, which lives in the message box under the footer,
opened behind the tray. The button now marks its own host while the menu
is open, and the tray stands level with the footer meanwhile, so the menu
comes out on top. An E2E check clicks where the open menu and the tray
overlap, with the message box at the bottom of the window as in WhatsApp.
