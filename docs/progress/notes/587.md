# Headless mode (#587)

`--headless` runs YapYap with no window, tray, welcome, update check or
crash review, and keeps the MCP server on for the run (ADR 0021, C55 in
ADR 0008). On Linux with no display it needs `--ozone-platform=headless`
on the command line, and adds `--disable-gpu`; without it or a display,
YapYap says how to start and exits. The `login-code.ts` probe reads the
logged-out page's QR code as modules, which `headless/pairing.ts` draws in
the terminal, and only there.
