# Suggestions follow new messages in the open chat (#707)

End-to-end tests on the fake WhatsApp page now check the cases #707 lists.
A newer message replaces the suggestions with its own. Three messages at
once ask once, for the last. A message that arrives while the user drafts
is answered, but its suggestions stay out of sight until the box is empty.
Nothing is asked while the window is hidden, and the suggestions catch up
once it shows. Nothing is asked while the assistant is off. They all held
already; no code changed.
