# Summaries of a chat's unread messages (#705)

Opening a chat with 10 or more unread messages offers a summary of them:
a **Summarize N unread** chip first in the bar's row, which turns into
**Summarizing…** while the model writes, then a card over the end of the
chat with **For you**, **Decisions and dates** and **Everything else**,
**Show First Unread** and a close button. WhatsApp marks messages read as
the chat opens, so the follow loop's look now also hands over the chat
list's unread badges, as `hash:count` pairs named by the same fingerprint
as the open chat's header, and the count is the badge's at the look
before. The request is the shared instructions, which gain a section on
summarizing, the chat context unchanged, then a task that names the
count; only the fenced `<for-you>`, `<decisions>` and `<rest>` sections
are shown, as plain text. The offer shows only in chats the assistant may
read, once it is set up, and while the new **Offer summaries of unread
messages** switch (`assistant.summaries`, on by default) is on. The
summary is held only in memory. **Mark all as read** is not offered:
opening the chat already marks the messages read.
