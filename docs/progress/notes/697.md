# Performance traces show which functions ran (#697)

Traces now include V8's sampled JavaScript call stacks
(`disabled-by-default-v8.cpu_profiler`), so Perfetto and the Chrome
DevTools Performance panel can show which functions a slow script ran,
WhatsApp's or YapYap's. The trace's confirmation and the troubleshooting
guide say the trace holds which parts of the code ran; it still holds no
messages, memory dumps or screenshots.
