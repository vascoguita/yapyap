# Contributing

Contributions are welcome. The full guide lives in
[CONTRIBUTING.md](https://github.com/vascoguita/yapyap/blob/master/CONTRIBUTING.md)
and covers setup, commands, workflow, repository settings, secrets, and the
extension key rotation procedure.

## In short

1. Read the [Code of Conduct](https://github.com/vascoguita/yapyap/blob/master/CODE_OF_CONDUCT.md).
2. Pick an issue from the [project board](https://github.com/users/vascoguita/projects/5).
3. Branch as `type/short-description` and make small, signed
   [Conventional Commits](https://www.conventionalcommits.org/).
4. Keep coverage at 100%. Mutation scores must stay at or above 90% for
   security-critical modules.
5. Open a pull request that links the issue and includes test evidence.

To translate YapYap, see [Translations](/translations).

Architecture and design decisions are recorded in the
[Architecture Decision Records](/adr/). Report vulnerabilities privately as
described in the
[security policy](https://github.com/vascoguita/yapyap/blob/master/SECURITY.md).
