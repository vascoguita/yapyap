# 0008. Requirement conflicts and resolutions

- Status: Accepted (living document: append, never rewrite)
- Date: 2026-10-18

## Context

The project's requirements sometimes pull against each other. The priority
order is fixed: **security > correctness > user privacy > confidentiality >
tests and coverage > performance > code style**. Every conflict and how we
resolved it is recorded here.
