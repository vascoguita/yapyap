# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/vascoguita/yapyap/discussions)
- **Bugs:** [open a bug report](https://github.com/vascoguita/yapyap/issues/new?template=bug_report.yml).
  Please attach the output of **Help → Copy diagnostics**. It is redacted and
  contains no message content.
- **Feature requests:** [open a feature request](https://github.com/vascoguita/yapyap/issues/new?template=feature_request.yml)
- **Plugin ideas:** [open a plugin request](https://github.com/vascoguita/yapyap/issues/new?template=plugin_request.yml)
- **Security issues:** see [SECURITY.md](SECURITY.md). Never report these in public.
- **Documentation:** https://vascoguita.github.io/yapyap/

YapYap is an unofficial client and is not affiliated with WhatsApp or Meta.
For problems with your WhatsApp account itself, contact WhatsApp support.
